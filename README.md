# ProNirmaan Solutions (3D)

A high-performance, scroll-based 3D frame animation web experience for **ProNirmaan Solutions — Civil Works & Control Demolition**.

## Features
- **300-Frame Scrollytelling Sequence**: Ultra-smooth canvas scrubbing synchronized with mouse wheel / touch scroll.
- **Dynamic Geometric Slant**: Precision chevron border transition that activates smoothly as the hero video finishes.
- **Fixed Responsive Header**: Sleek top bar with contact details, branding logo, navigation links, and search estimator.
- **Comprehensive Corporate Sections**:
  - Building Better / From the Ground Up
  - Commercial Services (Construction, Demolition, Heavy Civil, Retrofit)
  - Project Portfolio & Case Studies
  - Interactive Project Estimator Modal
  - Complete Footer with Regional Operations, Certification Badges & Legal Links

## Getting Started

### Prerequisites
- Node.js (v18+)

### Installation & Run Locally
```bash
# Clone the repository
git clone https://github.com/fahimchaudhary/PRONIRMAAN-3D.git
cd PRONIRMAAN-3D

# Start local server
npm start
```

Open `http://localhost:5173` in your browser.
